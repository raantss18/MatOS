# Code de conduite

matOS est un projet pour les étudiants et les enseignants. Chacun doit s'y sentir le bienvenu, quel que soit son niveau.

**Ce que nous attendons**
- Être courtois et patient : beaucoup de participants apprennent, et personne n'est né en sachant installer Linux.
- Critiquer les idées, jamais les personnes.
- Être précis : une question claire, avec le contexte, reçoit une meilleure réponse.
- Respecter la vie privée : ne publiez ni mot de passe, ni donnée personnelle, ni message privé d'autrui.

**Ce que nous refusons**
- Les insultes, le harcèlement, les propos discriminatoires, les attaques personnelles.
- La publicité et les messages sans rapport avec le projet.

**Application.** Les messages qui enfreignent ces règles peuvent être modifiés ou supprimés, et leurs auteurs écartés des discussions. Pour signaler un comportement, ouvrez un échange privé avec un responsable du dépôt (voir la page du projet sur GitHub) ou signalez le message avec le menu « Report » de GitHub.

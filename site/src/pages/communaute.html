Communauté

matOS est faite pour les étudiants et les enseignants, et elle s'améliore avec leurs retours. Les échanges ont lieu sur GitHub (un compte gratuit suffit) ; tout y est public et consultable sans compte.

Contribuer

Pas besoin d'être développeur :

  • Tester matOS sur votre ordinateur (surtout les anciens) et envoyer un rapport de compatibilité.
  • Traduire : la page de bienvenue, le site et la documentation existent en français ; une version malgache est très souhaitée.
  • Recommander des livres libres pour les cours de mathématiques et d'informatique (licence libre obligatoire, vérifiée automatiquement).
  • Corriger ou compléter la documentation, ou le code : voir Construire et contribuer.

Règles du jeu

Soyez courtois, précis et patient : beaucoup de participants apprennent. Les discussions sont publiques ; ne publiez ni mot de passe ni donnée personnelle. Le code de conduite s'applique partout.

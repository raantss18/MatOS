Télécharger matOS

Version {{version}} — ISO hybride pour PC 64 bits (BIOS et UEFI). Elle pèse environ 8,3 Go et tient sur une clé USB de 16 Go.

Pourquoi plusieurs parts ?

GitHub limite chaque fichier à 2 Go. L'ISO est donc découpée en 5 parts d'environ 2 Go. Le script ci-dessous les télécharge, vérifie chacune, reprend après une coupure de connexion et recompose l'ISO.

En quatre étapes

  1. Télécharger l'ISO

    Linux, macOS, ou Windows avec Git Bash (installé avec Git pour Windows). Prévoir 10 Go d'espace libre.

    curl -fLO https://raw.githubusercontent.com/raantss18/MatOS/main/scripts/telecharger-matos.sh
    bash telecharger-matos.sh

    Pour une version précise : bash telecharger-matos.sh v{{version}}. Le script n'a été testé que sous Linux.

    Sans le script (Windows ou téléchargement manuel)

    Téléchargez toutes les parts du tableau ci-dessous dans un même dossier, puis recomposez-les :

    Windows (Invite de commandes, dans le dossier des parts) :

    copy /b matos-{{version}}-ralambo-amd64.hybrid.iso.part-00+matos-{{version}}-ralambo-amd64.hybrid.iso.part-01+matos-{{version}}-ralambo-amd64.hybrid.iso.part-02+matos-{{version}}-ralambo-amd64.hybrid.iso.part-03+matos-{{version}}-ralambo-amd64.hybrid.iso.part-04 matos-{{version}}-ralambo-amd64.hybrid.iso

    Linux, macOS :

    cat matos-{{version}}-ralambo-amd64.hybrid.iso.part-* > matos-{{version}}-ralambo-amd64.hybrid.iso

  2. Vérifier l'empreinte

    Le script l'a déjà fait. Pour contrôler vous-même une ISO recomposée, comparez son empreinte SHA256 à celle de la version :

    sha256sum matos-{{version}}-ralambo-amd64.hybrid.iso

    Windows : certutil -hashfile matos-{{version}}-ralambo-amd64.hybrid.iso SHA256

  3. Créer la clé USB de démarrage

    Utilisez un outil qui écrit l'image telle quelle sur la clé :

    • Ventoy ou balenaEtcher (Windows, macOS, Linux) : choisissez l'ISO, choisissez la clé, lancez.
    • GNOME Disques (Linux) : « Restaurer l'image disque ».
    • En ligne de commande (Linux) : 
      sudo dd if=matos-{{version}}-ralambo-amd64.hybrid.iso of=/dev/sdX bs=4M status=progress conv=fsync

    Attention

    Tout le contenu de la clé est effacé. Avec dd, remplacez /dev/sdX par la clé (vérifiez avec lsblk) : une erreur efface un autre disque.

  4. Démarrer sur la clé

    Redémarrez le PC et ouvrez le menu de démarrage (souvent F12, Échap, F2 ou F9). Puis suivez le guide : Installer matOS.

Avant de télécharger

Configuration
Processeur64 bits (x86-64) uniquement. Les processeurs 32 bits ne sont pas pris en charge.
Mémoire4 Go de RAM suffisent pour le bureau et la plupart des logiciels ; SageMath, Lean avec Mathlib, RStudio et GeoGebra sont gourmands.
Disque32 Go libres pour l'installation (l'installateur l'exige).
Clé USB16 Go (pas de DVD : l'ISO dépasse 4,7 Go).

Modules, persistance et outils pour enseigner

Les modules hors ligne

L'ISO de matOS contient ce dont presque tout le monde a besoin et tient sur une clé de 8 Go. Le reste est rangé dans des modules : un fichier .matmod par module, que l'on copie sur une clé USB et que l'on se passe de main en main. Aucune connexion n'est nécessaire pour les installer.

Installer un module

  1. Récupérez le fichier .matmod : sur la clé d'un camarade ou d'un enseignant, ou sur la page Télécharger.
  2. Ouvrez le menu Modules matOS, choisissez le fichier, validez.

Ou dans un terminal :

sudo matos-modules installer matos-encyclopedie-2026.10.matmod
matos-modules liste

matOS compare l'empreinte SHA256 du fichier à la liste des modules de sa version : un fichier abîmé ou modifié est refusé. Pour retirer un module : sudo matos-modules retirer NOM.

Pourquoi certains modules demandent un système installé

lean et preuve-calcul installent des logiciels. Dans une session live simple, tout ce qui est installé va dans la mémoire vive : avec 4 Go, il n'y a pas la place. matOS le vérifie avant de commencer et vous le dit. Deux solutions : la persistance sur la clé, ou installer matOS.

Sur le disque, lean et preuve-calcul occupent environ 3 Go chacun une fois installés.

Testé dans une machine virtuelle à 4 Go de RAM, sur un système installé : lean et preuve-calcul s'installent sans réseau en une minute chacun, un premier projet Lean se compile en 45 secondes, Coq, Scilab et RStudio sont présents. Non testé sur du vrai matériel.

Garder ses fichiers sur la clé (persistance)

Sans persistance, tout ce que vous enregistrez dans la session live disparaît à l'extinction. matOS peut utiliser la place libre de la clé pour conserver vos fichiers, vos réglages et les modules installés, sans rien installer sur l'ordinateur.

  1. Démarrez sur la clé.
  2. Ouvrez le menu Conserver mes fichiers sur la clé et validez (ou sudo matos-persistance creer).
  3. Redémarrez sur la clé : la persistance est active. Ce que vous avez enregistré avant ce redémarrage n'est pas conservé.

Conditions : la clé a été écrite directement (balenaEtcher, GNOME Disques, dd) et il lui reste au moins 1 Go libre. Sur une clé de 8 Go, il reste environ 3,8 Go ; une clé de 16 Go ou plus est préférable pour les modules lean ou preuve-calcul. Avec Ventoy, l'image est un fichier et non une partition : utilisez la persistance propre à Ventoy.

Testé dans une machine virtuelle, sur une clé simulée de 7,4 Go : création de la partition, puis fichiers et réglages retrouvés aux démarrages suivants. Non testé sur de vraies clés.

Pour les enseignants

Modèles LaTeX

Le dossier Modèles de votre dossier personnel contient quatre documents prêts à compiler : Cours, Feuille de TD, Sujet d'examen et Diaporama (Beamer). Dans le gestionnaire de fichiers : clic droit, « Créer un document », puis ouvrez le fichier dans TeXstudio.

Partage en salle

Pour distribuer un dossier (sujets, polycopiés, modules) aux ordinateurs d'une salle sans Internet : menu Partage en salle, choisissez le dossier. matOS affiche une adresse du type http://192.168.1.20:8080/ que les autres ouvrent dans leur navigateur. Les ordinateurs doivent être sur le même réseau : celui de la salle, ou un point d'accès Wi-Fi créé depuis l'icône réseau de votre portable. Le partage est en lecture seule et s'arrête quand vous fermez la fenêtre.

Le partage en salle n'a pas encore été testé entre plusieurs machines réelles.

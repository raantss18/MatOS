VSCodium préconfiguré

VSCodium (VS Code sans suivi) est livré avec les extensions Lean 4, LaTeX Workshop, Python, Jupyter et un thème d'icônes, figées à une version précise et sans mise à jour automatique : l'éditeur ne change pas sous vos pieds.

Ce que matOS ne contient pas

  • Les composants facultatifs de SageMath (voir Premiers pas), pour alléger l'ISO.
  • Les complétions C++ de RStudio : le paquet libclang n'est pas installé (sudo apt install libclang-dev les rétablit).

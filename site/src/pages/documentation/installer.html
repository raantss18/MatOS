Installer matOS

Une installation complète prend 6 à 11 minutes et ne demande aucune connexion (testé sans réseau).

Avant de commencer

« Effacer le disque » supprime tout ce que contient le disque choisi. Sauvegardez vos fichiers. L'installation à côté de Windows (double amorçage) n'a pas été testée.

Ce qu'il faut

  • Un PC 64 bits avec au moins 4 Go de RAM et 32 Go libres sur le disque.
  • Une clé USB de 16 Go avec l'ISO (voir Télécharger matOS).

  1. Démarrer sur la clé

    Branchez la clé, redémarrez et ouvrez le menu de démarrage (souvent F12, Échap, F2 ou F9 selon le constructeur). Choisissez la clé : si elle apparaît deux fois, essayez d'abord l'entrée « UEFI ».

    Le menu matOS s'affiche : validez Live system (amd64) avec Entrée. Le bureau apparaît en une à deux minutes sur une machine à 4 Go.

    Les deux modes, BIOS et UEFI, ont été testés. Secure Boot n'a pas été testé : si la clé ne démarre pas, désactivez-le dans le BIOS.

  2. Découvrir avant d'installer (facultatif)

    La session « live » fonctionne depuis la clé sans rien modifier sur le disque. Si l'écran se verrouille après quelques minutes, le mot de passe est live.

  3. Lancer l'installateur

    Cherchez Installer matOS dans le menu des applications. Raccourci qui fonctionne toujours : appuyez sur Alt+F2 et tapez :

    calamares-install-debian

  4. Répondre aux questions

    Les pages de l'assistant
    PageÀ savoir
    BienvenueChoisissez la langue du système.
    EmplacementLe fuseau par défaut est Madagascar (Indian/Antananarivo). Les nombres et dates suivent le pays choisi, donc en malgache ; le bouton « Modification… » permet de choisir le français.
    ClavierFrançais par défaut.
    PartitionsChoisissez le disque, puis « Effacer le disque ». « Partitionnement manuel » est pour les utilisateurs avertis. La case « Chiffrer le système » n'a pas été testée.
    UtilisateursNom, identifiant, nom de l'ordinateur, mot de passe. Il n'y a pas de compte « root » : votre utilisateur est administrateur avec sudo.
    RésuméRelisez, puis « Installer ».

  5. Redémarrer

    À la fin, laissez « Redémarrer maintenant » coché, retirez la clé quand l'ordinateur s'éteint. Le premier démarrage prend moins de deux minutes sur une machine à 4 Go (mesuré dans une machine virtuelle).

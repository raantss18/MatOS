Ajouter votre machine

Un rapport prend deux minutes : le modèle du PC, le processeur, la mémoire, le mode de démarrage (BIOS ou UEFI), et ce qui marche ou non. Vos rapports apparaissent dans la liste des rapports de compatibilité.

Envoyer un rapport de compatibilité

Pour connaître les caractéristiques de votre machine, dans une session matOS :

lscpu | grep "Model name"; free -h; [ -d /sys/firmware/efi ] && echo UEFI || echo BIOS

Premiers pas

Le bureau

matOS utilise XFCE, un bureau léger. Le menu matOS (en bas à gauche) classe les logiciels ; la catégorie Mathématiques regroupe ceux des cours. Le dossier Bibliothèque du bureau contient les livres libres (en lecture seule : copiez un livre dans votre dossier personnel pour l'annoter).

La page Bienvenue dans matOS s'ouvre au premier démarrage ; vous la retrouvez dans le menu des applications.

Lancer les logiciels en une commande

Ouvrez un terminal (menu des applications, « Terminal »).

Un premier projet Lean

matos-lean-projet MonProjet
codium MonProjet

Ouvrez Projet/Basic.lean. Mathlib est déjà compilée : aucun téléchargement. Pour compiler en terminal : cd MonProjet && lake build. N'utilisez pas lake update : Mathlib est partagée en lecture seule et figée à la version de matOS.

Ajouter des composants de SageMath

Pour alléger l'ISO, certains composants de SageMath ne sont pas installés (compilateurs conda, Java et Jmol, giac, pandoc, et des paquets Python comme scikit-learn ou manim). Ils s'ajoutent à l'identique (mêmes versions) quand vous avez une connexion :

matos-sage-extras liste
sudo matos-sage-extras installer python

Mises à jour

sudo apt update && sudo apt upgrade

Cela met à jour les paquets Debian. Les applications de /opt/matos (SageMath, Lean, GeoGebra) sont figées : une mise à jour Debian ne peut ni les casser ni les remplacer ; elles évoluent avec les nouvelles versions de matOS.

Documentation hors ligne

La documentation de Python, SymPy, R, Maxima, Octave, Gnuplot, Coq, Singular, Git et LibreOffice (aide en français) est installée, ainsi que les pages de manuel en français (man) et la Debian Reference.

Construire et contribuer

matOS est un logiciel libre : tout ce qui sert à fabriquer l'ISO est dans le dépôt GitHub.

Reconstruire l'ISO

Seul prérequis : Docker ou Podman. Le build se fait dans un conteneur Debian 13, sur n'importe quelle distribution. Prévoir environ 80 Go de disque libre et plusieurs heures la première fois.

git clone https://github.com/raantss18/MatOS.git && cd MatOS
./build.sh --rapide   # ISO de test sans SageMath ni Lean
./build.sh            # ISO complète (≈ 8,3 Go)
./build.sh --test     # démarre l'ISO dans QEMU

Principes : le build échoue plutôt que de produire une image incomplète ; tout ce qui est téléchargé a une version et une empreinte SHA256 (versions.env) ; les personnalisations sont des paquets matos-* qui ne modifient jamais les fichiers d'autres paquets.

Publier une version

  1. Changer MATOS_VERSION dans versions.env et noter les changements dans CHANGELOG.md.
  2. Construire et tester l'ISO, puis fusionner dans main (pull request).
  3. Vérifier le découpage sans rien envoyer : scripts/publier-release.sh --a-blanc.
  4. Créer la version en brouillon : scripts/publier-release.sh, puis la rendre publique : scripts/publier-release.sh --publier.

La page Télécharger lit automatiquement la dernière version publiée.

Ajouter un livre libre

Un livre n'entre dans la bibliothèque que si sa licence libre est constatée dans le texte du PDF.

scripts/livre-verifier.sh Mathematiques/mon-livre.pdf https://exemple.org/livre.pdf

Le script vérifie que c'est un PDF, cherche la licence et affiche la ligne à copier dans MATOS_BOOKS (versions.env).

Modifier ce site

Les sources sont dans site/src/ (pages en fragments HTML, une feuille de style, un petit JavaScript facultatif). La charte est dans site/DESIGN.md. Pour prévisualiser :

python3 scripts/generer-site.py --verifier && python3 -m http.server -d site/public 8000

Puis ouvrez http://localhost:8000. Le script ne demande aucune installation (Python seulement) et vérifie les liens, les ancres et les textes alternatifs. Le site est publié automatiquement après chaque fusion dans main.

Proposer une modification

Ouvrez une pull request décrivant ce que vous avez changé et comment vous l'avez testé. Lisez d'abord le guide de contribution et le code de conduite.

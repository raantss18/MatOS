Confidentialité

Les statistiques anonymes de matOS

Pour savoir combien de machines utilisent matOS, le système envoie au plus une fois par jour, quand il y a du réseau, quatre informations et rien d'autre :

Contenu exact de l'envoi
ChampExemple
Version de matOS0.6
Mode : session live ou système installéinstalle
Langue du systèmefr
Pays du fuseau horaireMG

Il n'y a aucun identifiant : on compte des envois, pas des personnes. Ni nom, ni fichier, ni matériel, ni position. Comme pour tout accès à Internet, le serveur reçoit l'adresse IP de la connexion ; matOS ne l'ajoute pas aux statistiques. Les données sont stockées chez Supabase, dans une table où le système ne peut qu'ajouter des lignes (personne d'autre ne peut les lire publiquement).

Voir ce qui est envoyé

matos-stats --montrer

Désactiver les statistiques

Menu des applications → « Statistiques anonymes », ou :

sudo matos-stats --desactiver

Pour réactiver : sudo matos-stats --activer. L'état : matos-stats --etat.
